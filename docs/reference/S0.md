# Survival function for age-at-failure

Computes \\S_0(t)=Pr(T_0\>t)\\.

## Usage

``` r
S0(t, model, ...)
```

## Arguments

- t:

  Numeric vector of times.

- model:

  One of `"uniform"`, `"exponential"`, `"gompertz"`, `"makeham"`, or
  `"weibull"`.

- ...:

  Model parameters.

## Value

Numeric vector of survival probabilities.
