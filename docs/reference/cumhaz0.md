# Cumulative hazard for age-at-failure

Computes \\\Lambda_0(t)\\.

## Usage

``` r
cumhaz0(t, model, ...)
```

## Arguments

- t:

  Numeric vector of times.

- model:

  One of `"uniform"`, `"exponential"`, `"gompertz"`, `"makeham"`, or
  `"weibull"`.

- ...:

  Model parameters.

## Value

Numeric vector.
