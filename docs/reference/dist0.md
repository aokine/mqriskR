# Distribution functions for age-at-failure

Distribution functions for age-at-failure

## Usage

``` r
F0(t, model, ...)

f0(t, model, ...)
```

## Arguments

- t:

  Numeric vector of times.

- model:

  One of `"uniform"`, `"exponential"`, `"gompertz"`, `"makeham"`, or
  `"weibull"`.

- ...:

  Model parameters.

## Value

Numeric vector.
