# Convert life-table values to survival probabilities

Converts life-table survivor values \\l_x\\ into survival probabilities
\\S_0(x) = l_x / l_0\\.

## Usage

``` r
lx_to_S0(lx)
```

## Arguments

- lx:

  Numeric vector of life-table survivor values.

## Value

Numeric vector of \\S_0(x)\\ values.
